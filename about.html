AI Image Recognition

AI Image Recognition is a web-based Artificial Intelligence application that identifies objects present in images.

The system uses TensorFlow.js and the MobileNet machine learning model to classify images directly inside the web browser.

🛠️ Technologies

  • HTML5
  • CSS3
  • JavaScript
  • TensorFlow.js
  • MobileNet
  • Web Camera API
  • LocalStorage

🎯 Objectives

  • Recognize objects automatically
  • Provide confidence scores
  • Support image upload
  • Support live camera
  • Maintain recognition history

🧠 AI Model

MobileNet

MobileNet is a lightweight deep-learning model designed for image classification and computer vision applications.
